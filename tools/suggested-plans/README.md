# مكتبة «الخطط الدراسية المقترحة» — مصدر البيانات وأدوات التوليد

المصدر: «النشرة التوجيهية للعام الدراسي 2026-2027» الصادرة عن وزارة التربية والتعليم بسلطنة عُمان
(خطة توزيع المحتوى لمدارس الفترة الواحدة ومدارس الفترتين — مادة المهارات الموسيقية).

- `data_g1_4.py` / `data_g5_10.py` / `data_g11_12.py`: نقل يدوي صفًا بصف من صور صفحات النشرة (الصفحات صور مطبوعة، لا نص قابل للاستخراج).
  كل صف: (الأسبوع، بداية، نهاية، الوحدة، الدرس، حصص الفترة الواحدة، حصص الفترتين[, نص التاريخ كما ورد عند التعارض]).
- `validate.py`: يتحقق أن كل تاريخ يقع داخل أسبوعه الدراسي (الأحد–الخميس)، وتسلسل الأسابيع، ومجموع الحصص الأسبوعية (الصفان 11 و12)،
  ويقارن الدروس وأسابيعها مع الاستخراج السابق `src/data/semester-plans.json`.
- `build_xlsx.py OUT_DIR` ثم `fix_ncr.py OUT_DIR`: ينشئ 24 ملف Excel منسقًا (RTL، تجميد الرأس، مرشحات، إعداد طباعة A4 أفقي، ورقة «تعليمات ومصدر الخطة»)،
  ثم يحوّل المراجع الرقمية في XML إلى نص UTF-8 حتى تُقرأ الرموز الموسيقية صحيحة.

الملفات المنشورة مع التطبيق: `public/suggested-plans/grade-NN/semester-N.xlsx`، وفهرسها: `src/modules/lesson-plans/data/suggestedLibrary.js`.
