# Oriental Maestro — الأورج الافتراضي (للمطورين)

المسار: `private-games/oriental-organ-piano/` — يُخدم محميًا عبر `/play/oriental-organ-piano/` (جلسة موقّعة، مشتركون فقط).
بطاقة «الكيبورد الشرقي والغربي» في «الألعاب الموسيقية» (`src/lib/gamesConfig.js`، id `oriental-keyboard`) تفتحه عبر `labId`،
والرابط القديم `/dashboard/resources/oriental-keyboard` يُحوَّل إليه تلقائيًا. النسخة العامة القديمة `public/games/oriental-keyboard` لم تعد مستعملة.

## البنية
| الملف | الدور |
|---|---|
| `index.html`, `css/organ.css` | الواجهة: شاشة LCD، الأصوات، الإيقاعات، المقابض، صف المقامات، الأدوات التعليمية، لوحة المفاتيح (ثابتة أسفل الشاشة) |
| `js/theory.mjs` | **المصدر الوحيد** للأسماء والترددات (`pitchOf`, `labelOf`, `westernName`, جدول ص 49) — من المرحلة الأولى |
| `js/keymap.mjs` | لوحة الحاسوب (e.code، تعمل مع الكيبورد العربي) |
| `js/maqamat.mjs` | المقامات (11) والسلالم الغربية (6): الدرجات بربع التون، تهجئة بالحروف المتتالية، الضبط المشتق |
| `js/rhythms.mjs` | الإيقاعات (14) ومصادرها، بطاقات التراث، التحقق من إيقاعات المستخدم |
| `js/sequencer.mjs` | جدولة بالنظر للأمام على ساعة الصوت: تغيير الإيقاع مع الدورة التالية، حشوة، ختام، مترونوم، نقر السرعة |
| `js/drums.mjs` | أصوات الإيقاع مولّدة (دوال خالصة) |
| `js/voices.mjs` | تعريف الأصوات الـ20 ومصادرها وتراخيصها ومعايرتها |
| `js/engine.mjs` | محرك WebAudio: أجزاء (رئيسي/طبقة/يسرى/إيقاع)، صدى وكورس، ضاغط، تحميل كسول، حلقات تلقائية بمزج متقاطع |
| `js/plucks.mjs`, `js/calib.mjs` | النمذجة الفيزيائية للقانون والعود، ومنحنيات العلو |
| `js/app.mjs` | منطق الواجهة والأوضاع والذاكرة والمسجّل والتدريبات وMIDI |
| `samples/<set>/manifest.json` | لكل عينة: `m` (MIDI)، `c` (تصحيح الطبقة بالسنت)، `g` (كسب dB)، ونقاط الحلقة إن وُجدت |

## مبادئ لا يجوز كسرها
1. لا يُكتب اسم نغمة يدويًا: كل اسم/تردد من `theory.mjs` (والمقامات تشتق أسماءها من الجدول).
2. الضبط كائن غير قابل للتعديل؛ أزرار الأرباع تُنتج ضبطًا جديدًا (لا تراكم في الخفض).
3. النغمة المضغوطة تكمل بطبقتها حتى رفع الإصبع؛ التبديل بين الأوضاع/الأصوات/المقامات يطبق على النغمات الجديدة (لا نغمات عالقة).
4. لا عينة بلا مصدر وترخيص مدوّنين، ولا إيقاع تراثي بلا تدوين موثوق.

## إضافة صوت بعينات
1. ضع `samples/<set>/` بملفات mp3 باسم النغمة (`C4.mp3`، `Eb4.mp3`، `Fs4.mp3`) و`manifest.json`:
   `{ "set", "ext": "mp3", "kind": "sustained" | "decaying", "notes": { "C4": { "m": 60, "c": 0, "g": 0 } }, "source", "license" }`
2. أضف تعريفه في `js/voices.mjs` (المصدر والترخيص `lic` إلزاميان) ثم قِس `trim` كما في الاختبار.
3. أضف السطر في `CREDITS.md` وفي نافذة المصادر (تُبنى تلقائيًا من `VOICES`/`LICENSES`).

## إضافة إيقاع
أضف كائنًا في `RHYTHMS` بمسار `dt` (D/T/k/-) أو مسارات الطقم، ومصدرين على الأقل في `src`. الاختبار يتحقق من الأطوال والرموز والمصادر.

## الاختبارات
- `node --test tests/oriental/` — النظرية والمقامات والإيقاعات والمجدول وأصوات الإيقاع (35 اختبارًا).
- اختبار المتصفح الشامل والقياس الصوتي يعملان عبر `tests/harness.mjs` (معالجات الحماية الحقيقية) — انظر تقرير التسليم.
