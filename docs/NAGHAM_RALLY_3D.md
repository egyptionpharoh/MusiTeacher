# رالي النغم ثلاثي الأبعاد — Nagham Rally 3D

لعبة سباق موسيقية: الطالب يقود سيارة سباق أو موتوسيكل، ويسمع سؤالًا من «الراديو» أو يقرأه على «لوحة القيادة»،
ثم يدخل مسار الإجابة الصحيحة عند المفترق. المسار الصحيح بوابة خضراء ونقاط، والخطأ حواجز إسفنجية.

- المسار: `private-games/nagham-rally-3d` · صفحة التشغيل: `/dashboard/resources/lab/nagham-rally-3d`
- التسجيل: عنصر `nagham-rally-3d` في `src/data/virtualGames.js` و`src/data/gameDevices.js` (tablet).

## البنية
| الملف | الدور |
|---|---|
| `src/main.js` | المشهد، تحميل الشخصية، المرآب، لوحة المفاتيح، الحلقة |
| `src/character/driver.js` | تحميل العازف/العازفة من `_shared/3d` ووضعيتا القيادة (سيارة/موتوسيكل) واليدان على المقود كل إطار |
| `src/character/racewear.js` | بدلة القيادة، القفازات، الخوذتان، حزام الأمان، ذيل سترة الركوب |
| `src/vehicles/car.js`, `moto.js`, `parts.js` | المركبتان (مقود دوّار، شوكة مائلة، ميل الدراجة) |
| `src/world/world.js`, `bend.js` | الحلبات الثلاث، العناصر المعاد تدويرها، «العالم المنحني» |
| `src/world/gates.js`, `signs.js` | جسر اللافتات، الحواجز، البوابات، رسم اللافتات |
| `src/data/content.js` | مكتبة التحديات (8 مجالات × 4 مستويات) — لإضافة مجال: عنصر جديد في `DOMAINS` |
| `src/audio/audio.js` | تشغيل الأسئلة بعينات حقيقية + المحرك والمؤثرات |
| `src/game/race.js`, `fx.js` | القيادة، المفترقات، الأنماط، الكاميرا، الارتطام |
| `src/ui/ui.js`, `style.css` | شاشة البداية، مصنع السباقات، لوحة السباق، النتائج |

## للمعلم
- «مصنع السباقات»: المجالات، المستوى، عدد التحديات، النمط (تدريب/نقاط/بطولة)، زمن الإجابة، مرات الإعادة، الحلبة، قفل المركبة، معاينة.
- «رمز السباق» يُضاف إلى الرابط `?race=الرمز` ليفتح الطلاب السباق نفسه.
- لوحة الأبطال محفوظة في المتصفح (localStorage) على الجهاز نفسه.

## روابط الاختبار
`?driver=male|female` · `?vehicle=car|moto` · `?low` (أداء منخفض) · `?noshadow` · `?ts=4` (تسريع الزمن للاختبار الآلي فقط)
