# لعبة «إيقاعات الفنون العُمانية» (omani-rhythms)

المجلد: `private-games/omani-rhythms/` — تُخدم محميًة عبر `/play/omani-rhythms/` مثل باقي ألعاب الاستوديو.
البطاقة: «عالم الألعاب الموسيقية» (`src/lib/gamesConfig.js` عبر `labId`) + فئة «الآلات الإيقاعية» في استوديو الموسيقى (`src/data/virtualGames.js`).

## الأقسام
- **مكتبة الفنون**: بطاقة لكل فن (الصور، النبذة، الآلات، «استمع للإيقاع كاملًا»، «ادخل استوديو التفكيك»).
- **استوديو التفكيك**: مسرح ثلاثي الأبعاد للآلات + بطاقة لكل آلة (وحدها / كتم / منفرد / مستوى الصوت / سماع الدُّم والتك) + المدوّنة بمؤشر متحرك (عرض مجمّع أو لكل آلة) + السرعة والمستوى العام والتكرار والإيقاف المؤقت.
- **وضع المعلم**: اختيار الفن، البناء التدريجي (آلة بعد آلة مع شرح دورها)، كتم الكل/الفرقة كاملة، «عرض على السبورة»، اختصارات: المسافة · 1–6 · S · Esc.
- **وضع الطالب**: تعرّف على الآلة · أيّ آلة صامتة؟ · أعِد بناء الفرقة · أيّ فنٍّ هذا؟ · اختبار المعرفة.
- **المصادر والمراجع**: كل مرجع مع الصفحات/الرابط وتاريخ الاطلاع، والفصل بين الموثّق ومعالجة اللعبة، وتراخيص الأصوات والصور.

## إضافة فن جديد (ملف واحد: `src/data.js`)
1. أضف عنصرًا في `ARTS`:
```js
{ id: 'new-art', name: 'الاسم', title: 'فن الاسم', src: 'g5', model: 'النموذج (n)', meter: [2, 4],
  bpm: { v: 90, source: false },            // source: true فقط إذا وردت السرعة في المدوّنة
  region: '…', kind: 'فن نسائي', blurb: '…', more: '…', others: '…', tip: '…',
  tracks: [ { inst: 'rahmani', p: 'D4 T4 | [D2 D2] T4' }, { inst: 'kasir', p: '…' } ] }
```
   صيغة المدوّنة: `D` دُم (رأس سفلي) · `T` تك (رأس علوي) · `R` سكتة · الرقم = المدة بالدوبل كروش (1، 2 كروش، 3 كروش منقوط، 4 نوار، 6 نوار منقوط)
   · `|` نهاية مازورة · `[ … ]` علامات بعارضة واحدة · `>` نبر · `~` رباط مع العلامة التالية.
   أي مازورة طولها خطأ تُرفض تلقائيًا برسالة واضحة.
2. إن احتاج آلة جديدة: عنصر في `INSTRUMENTS` + دالة مجسّم في `src/models.js` + صورتها `assets/img/<model>.png` + عيناتها في `assets/audio`.
3. أضف مرجعه في `SOURCES` وتوقّع ضرباته في `tests/omani-rhythms.test.mjs`، ثم:
   `node --test tests/omani-rhythms.test.mjs`

## الدقة الإيقاعية
المحرك (`src/audio.js`) يجدول كل الضربات مسبقًا على ساعة الصوت (Web Audio) بدقة العيّنة؛ لكل آلة مسار مستقل
(كسب المسار ← بوابة الكتم ← الكسب العام). الكتم يغلق البوابة خلال ~10 ملّي ثانية ويُسكت حتى ذيل الرنين، والجدولة تستمر فلا يتأثر توقيت البقية.
المؤشر والإضاءة وحركة المجسّمات تتبع الزمن **المسموع** (لا لحظة الجدولة).
