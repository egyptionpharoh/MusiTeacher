# عازف العود ثلاثي الأبعاد (`oudist-3d`)

لعبة في «استوديو الموسيقى الافتراضي» (`/dashboard/resources` ← الآلات الوترية). تُخدم من `private-games/oudist-3d/` عبر آلية الحماية نفسها
(جلسة موقّعة، `/play/oudist-3d/...`، علامة مائية)، وتستعمل الشخصية المشتركة `private-games/_shared/3d/character` مثل الكمان والأكورديون والأورج.
الألعاب السابقة للعود (`oud-3d` مجسم فقط، `virtual-oud`، `oud-maqamat`) لم تُعدَّل.

## البنية
| الملف | الدور |
|---|---|
| `src/instrument/oud-model.js` | مجسم العود الإجرائي: قصعة من 21 ضلعًا، وجه بشمسيات مفرّغة فعلًا ورقمة، فرس، زند ولوحة أبنوس بلا دساتين، أنف، بنجق منحنٍ للخلف و12 ملوى، 11 وترًا (5 أزواج + قرار مفرد) تُضغط وتهتز، والريشة. |
| `src/instrument/oud-data.js` | الدوزان وأسماء الأوتار والنغمات وقاعدة الإصبع — مطابقة للعبة `oud-maqamat`: قرار دو٢ · يكاه صول٢ · عشيران لا٢ · دوكاه ري٣ · نوى صول٣ · كردان دو٤ (الصوت الفعلي؛ النوتة تُكتب أعلى بأوكتاف). |
| `src/audio/oud-audio.js` | صوت مولَّد (Karplus–Strong + رنين الجسم) منقول من `virtual-oud`، مع ذاكرة مؤقتة وجدولة على ساعة Web Audio. |
| `src/character/oudist.js` | وضعية الحمل (تُحسب من سطح الجسم/الثوب الفعلي)، اليد اليسرى (إبهام خلف الزند، أصابع مقوّسة، ملامسة مقيسة للوتر)، اليد اليمنى والريشة، كُمّ الساعد على حافة القصعة، وقياسات الاختراق. |
| `src/character/performer.js` | التوقيت: الإصبع يضغط قبل الصوت بـ25 م.ث، وطرف الريشة يعبر الوتر لحظة الصوت (↓/↑)، وكتم الوتر عند رفع الإصبع. |
| `src/character/life.js` | رمش وتنفس ونظر وحركة رأس (من لعبة الأورج، بأهداف نظر خاصة بالعود). |
| `src/character/dish-fix.js` | تصحيحات ثوب العازف في الجلوس (من الأكورديون). |
| `src/teaching/exercises.js` | الأوتار المطلقة، العجم، الراست (أرباع التون)، الكرد، ولحنان قصيران من تأليف MusiTeacher. |
| `src/ui/ui.js` | الأوضاع: تعرّف على العود · عزف حر (خريطة الزند + النقر على الزند في المشهد) · تعلّم موجّه · تمرين لحني، الكاميرا، زر «🔄 استبدال العازف». |

## المعايرة
ثوابت الحمل لكل شخصية في `src/config.js` (`hold`): العازفة تستعمل مسند قدم صغيرًا (7 سم) تحت القدم اليمنى — ممارسة شائعة عند عازفي العود — حتى يستقر قعر العود على فخذها.
يمكن تجربة قيم أخرى بالرابط أثناء التطوير (مثل `?opitch=18&oyaw=12&stool=0.05`) دون تعديل الملفات.

## الاختبار الآلي (ما قيس قبل التسليم)
- اختراق جلد اليدين في العود أثناء كل التمارين: ≤ 1.1 مم (اليسرى)، 0 (اليمنى وجلد الساعد).
- طرف الإصبع الضاغط فوق الوتر المضغوط: الوسيط 0.4 مم.
- تزامن عبور الريشة للوتر مع لحظة الصوت: 0–3 م.ث (دقة خطوة الاختبار).
- طرف الريشة لا يلمس الوجه (أقرب مسافة 8.4 مم أثناء الضرب).
