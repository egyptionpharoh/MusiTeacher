# مقاطع وطنية لمذياع الطريق في «رالي النغم»

ضع هنا تسجيلات الأغاني والأناشيد الوطنية التي تملك حق استخدامها في المنصة (مثل: حلوة عُمان، يا موطني، مقطع من النشيد الوطني).
ثم أضفها إلى `manifest.json` هكذا:

```json
{ "clips": [
  { "file": "halwa-oman.mp3", "title": "حلوة عُمان", "start": 12 },
  { "file": "ya-mawtini.mp3", "title": "يا موطني", "start": 0 }
] }
```

- `start`: الثانية التي يبدأ منها المقطع داخل التسجيل (اختر جزءًا معبّرًا).
- يُسمع المقطع ثوانيَ فقط أثناء مرور المركبة بجوار المحل، ثم يتلاشى.
- لا يُسمع أثناء الأسئلة السمعية، ويتحكم المعلم فيه من «إعدادات اللعبة».
- اللعبة لا تنزّل أي تسجيل من الإنترنت؛ تعمل بما في هذا المجلد فقط، وبدونه تكتفي بإيقاعات الفنون العُمانية.
